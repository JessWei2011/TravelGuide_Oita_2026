## ☁️ Google 試算表即時連線教學

若希望與旅伴共同在 Google 試算表上即時修改行程，並讓網頁自動連線抓取最新內容：

1. 開啟 Google Drive，建立一份新的 Google 試算表（Google Sheet）。
2. 將專案中的 `Oita_Trip_GoogleSheet_Template.csv` 匯入該試算表。
3. 點選試算表右上角 **「共用」➔ 變更為「知道連結的使用者皆可查看」**。
4. 複製網址中的試算表 ID：
   ```
   https://docs.google.com/spreadsheets/d/【這段就是試算表ID】/edit
   ```
5. 打開 `data.js`，將 ID 填入開頭處：
   ```javascript
   const GOOGLE_SHEET_ID = "您的試算表ID";
   ```
6. 重新整理網頁，行程表頂端即會顯示 `☁️ 即時連線 Google 試算表（已同步最新多人協作內容）`！
